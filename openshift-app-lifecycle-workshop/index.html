OpenShift Application Lifecycle Workshop

From "docker run on a VM" to a repeatable, monthly application lifecycle on OpenShift

This workshop series follows one application through its whole operational lifecycle on OpenShift: make it onboarding-ready, build it, deploy it with GitOps, observe it, back it up, patch its base image every month, verify it and restore it. Each session is a 60 to 90 minute live demo on a throwaway cluster, followed by two days of hands-on access so the team can repeat every step without fear of breaking anything.

The series is written for platform teams that are bringing many existing container workloads, often built by third-party vendors and running with docker or podman on standalone VMs, onto a shared OpenShift platform.

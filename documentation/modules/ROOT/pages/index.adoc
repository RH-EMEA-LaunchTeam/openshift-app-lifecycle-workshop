== From "docker run on a VM" to a repeatable, monthly application lifecycle on OpenShift

This workshop series follows one application through its whole operational lifecycle on OpenShift: make it onboarding-ready, build it, deploy it with GitOps, observe it, back it up, patch its base image every month, verify it and restore it. Each session is a 60 to 90 minute live demo on a throwaway cluster, followed by one to two days of hands-on access so the team can repeat every step without fear of breaking anything.

The series is written for platform teams that are bringing many existing container workloads, often built by third-party vendors and running with `docker` or `podman` on standalone VMs, onto a shared OpenShift platform.

.The lifecycle this series proves end to end
[cols="1,1,1,1,1,1,1,1",options="header"]
|===
| Build | Deploy | Run | Backup | Patch | Redeploy | Verify | Restore
| source to image | GitOps | logs and metrics | app and data | base image | verified rollout | security and ops | documented test
|===

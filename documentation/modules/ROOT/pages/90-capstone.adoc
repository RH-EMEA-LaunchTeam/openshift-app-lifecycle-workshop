== Planned steps

. Build the application through the pipeline
. Deploy it through GitOps
. Check metrics, logs and security status
. Take a backup
. Patch the base image, rebuild and redeploy
. Verify security and operations
. Restore from backup and verify
. Review gaps, risks and the remediation backlog

== What the session leaves behind

* A validated reference implementation
* An operational runbook
* A reusable onboarding pattern for future applications

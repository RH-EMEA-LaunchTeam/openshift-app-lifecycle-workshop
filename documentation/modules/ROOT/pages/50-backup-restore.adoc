== Planned steps

. Install and configure OADP with an object storage location
. Back up the namespace, including persistent volume data
. Schedule recurring backups with a retention policy
. Simulate data loss and restore into a new namespace
. Verify the restored application and data, and record the evidence
. Discuss what GitOps already recovers and what only a backup can recover

== What the session leaves behind

* A restore runbook
* Evidence from a restore test

== Questions to prepare

* What recovery time and recovery point objectives apply to platform workloads?
* Where can backup data be stored?

== Planned steps

. Environment strategy: production-only clusters, pre-production and disposable test clusters
. Apply governance policies to several clusters from one hub
. Compare one Argo CD per cluster with a central Argo CD
. Test platform changes (operators, upgrades) before they reach production
. Record the decisions in a decision log

== What the session leaves behind

* Decision log entries for environments and GitOps topology
* A starter set of governance policies

== Questions to prepare

* What should be the role of the management cluster?
* Which changes must be tested outside production first?
